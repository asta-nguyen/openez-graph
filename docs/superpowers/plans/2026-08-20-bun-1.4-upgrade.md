# Bun 1.4 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade OpenEZ Graph from Bun 1.3.14 to 1.4, replacing `smol-toml`, `tsx`, `concurrently`, and `@hono/node-server` with Bun built-ins, and adopting `bun test --parallel` as the default test command.

**Architecture:** Four bisectable commits, each shippable on its own. Commit 1 bumps Bun and removes dead deps (zero behavior change). Commit 2 swaps leaf deps for Bun built-ins (isolated 1-3 line diffs). Commit 3 swaps the web server binding from `@hono/node-server` to `Bun.serve` while keeping Hono as the router. Commit 4 adds `bun test` parallel flags. Hono, pnpm, tsup, turbo, vite, and chokidar stay.

**Tech Stack:** Bun 1.4, TypeScript, Hono, pnpm 10.10.0, tsup, turbo, Vite, React 19.

## Global Constraints

- Bun runtime: `>=1.4.0` (enforced in `apps/cli/package.json` `engines.bun`)
- `@types/bun`: `^1.4.0`
- Package manager stays pnpm 10.10.0 (`packageManager` field, `pnpm-lock.yaml`) — do NOT migrate to `bun install`
- tsup stays for CLI bundling — do NOT migrate to `bun build`
- turbo stays for typecheck — do NOT migrate to `bun run --filter`
- vite stays for web dev/build — do NOT migrate
- chokidar stays for file watching — no Bun 1.4 replacement exists
- Hono stays as the HTTP router — only the server binding changes
- `landing/` Next.js workspace is untouched
- Each commit must pass `pnpm typecheck` and `pnpm test` (or `pnpm test:serial` after Commit 4 lands)
- Follow existing code style: no comments added/removed unless asked, compact code, prettier-formatted
